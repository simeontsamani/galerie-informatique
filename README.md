# Galerie Informatique - Projet Cloud Computing

Étudiant : L3 IAGE - Informatique de Gestion
Prof : Baraka Kinywa

## Description
Petit site qui affiche 3 images sur l'informatique.
Les images ne sont PAS dans le dossier du projet, elles sont hébergées sur Cloudinary et affichées avec leurs liens.

## Technologies utilisées
- HTML / CSS
- Cloudinary pour héberger les images
- GitHub pour le code
- Vercel pour déployer le site

## Comment ça marche
1. J'ai téléversé mes 3 images sur Cloudinary
2. J'ai copié leurs liens URL
3. Je les ai mis dans le fichier index.html dans les balises <img src="...">
4. J'ai publié sur GitHub puis déployé sur Vercel

## Comment lancer en local
Ouvrir simplement le fichier index.html dans un navigateur.# galerie-informatique
